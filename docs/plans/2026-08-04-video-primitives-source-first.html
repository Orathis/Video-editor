First build: Thread Message Stack.

Prove the source-first contract with one collection primitive before generalizing anything. The shipping artifact remains one copied HTML file.

Implementation slice

  • Keep the current bubble markup, layout, GSAP timing, and visual defaults.
  • Replace the fixed message nodes with one messages[] JSON seam and a small local render loop.
  • Let the installer replace only that JSON block when structured message data is supplied.
  • Copy the whole HTML file into the project so every selector, keyframe, and script remains editable.
  • Use the existing CLI authentication, catalog install, preview, lint, check, and render paths.

Explicit cut line

  • No new component runtime or package dependency.
  • No universal primitive schema or shared slot protocol.
  • No nested array editor in Studio.
  • No migration of the other 24 primitives in this release.
  • No promise that every future primitive uses the same JSON shape.

First-migration acceptance

The same primitive renders 1, 6, and 20 ordered messages without clipping or silent truncation; the installer changes only the embedded data block; existing local source edits remain possible; and the project still passes the current HyperFrames lint, check, preview, and render workflow. Primitive two starts only after this journey is measured.

Start with one thin seam.

The first implementation proves arbitrary collections without changing the core renderer or building a universal visual schema.

Ship first

  • Convert Thread Message Stack from six hardcoded bubbles to an arbitrary JSON message array.
  • Let catalog install materialize user data into the copied source file.
  • Keep existing scalar variables for common Studio controls.
  • Preserve the current HyperFrames runtime, GSAP contract, lint, check, and render path.
  • Measure local query to Smart click, OAuth completion, install, and first render.

Do not build yet

  • A new universal component runtime.
  • A nested object and array editor in Studio.
  • A no-code scene graph that models every HTML and CSS capability.
  • A slot protocol shared by every primitive before two real migrations need it.
  • A compatibility layer that hides or wraps the installed source.

Acceptance example A1

A user asks for 20 messages. The installed primitive renders all 20 in authored sequence, then the user can change any bubble, selector, keyframe, or script directly without ejecting from a framework.
