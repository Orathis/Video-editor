## Finish a version

<Steps>
  <Step title="Watch it through">
    Check the opening, final frame, and audio ending.
  </Step>
  <Step title="Run the check">
    Fix a visible warning, or copy it to the agent when the source needs work.
  </Step>
  <Step title="Export a version">
    Studio dates the file and keeps past renders in the queue. Watch the exported file once.
  </Step>
</Steps>
