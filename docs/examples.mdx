## One real project, open end to end

The Reference Project starts from the same beginner request used in the Quickstart:

```text
Using /hyperframes, make a 10-second product intro for https://example.com.
```

<Steps>
  <Step title="The agent confirms the brief">
    It keeps the real captured page, uses the page's own words, and settles the one missing creative
    decision: show the site as it is. [Read the brief](https://github.com/heygen-com/hyperframes/blob/main/examples/docs-reference-project/BRIEF.md).
  </Step>
  <Step title="The source stays inspectable">
    The capture, storyboard, script, media, captions, and composition are ordinary project files.
    [Open the project](https://github.com/heygen-com/hyperframes/tree/main/examples/docs-reference-project).
  </Step>
  <Step title="The weak first version is revised">
    The page capture becomes readable at 1:1, decorative noise is removed, and the edit gains measured
    narration, captions, music, sound, and variables. [See the exact before/after decisions](https://github.com/heygen-com/hyperframes/blob/main/examples/docs-reference-project/VERIFICATION.md#2-v1--v2).
  </Step>
  <Step title="The project passes the real gates">
    Lint, browser checks, 19 inspected frames, and the final render all pass. The report includes the
    remaining info-level findings instead of hiding them. [Read the verification report](https://github.com/heygen-com/hyperframes/blob/main/examples/docs-reference-project/VERIFICATION.md).
  </Step>
</Steps>

## Start from a template

Create a project with a working example:

```bash
npx hyperframes init my-video --example <name>
```

| Example         | Good starting point for                      |
| --------------- | -------------------------------------------- |
| `warm-grain`    | Branding, lifestyle, and editorial work      |
| `play-mode`     | Energetic social videos and product launches |
| `swiss-grid`    | Technical, structured, and corporate stories |
| `kinetic-type`  | Type-led promos, intros, and title cards     |
| `decision-tree` | Explainable diagrams and tutorials           |
| `product-promo` | Multi-scene product showcases                |
| `nyt-graph`     | Editorial charts and data stories            |
| `vignelli`      | Bold portrait announcements                  |
| `blank`         | Agent-generated or fully custom work         |

<Tip>
  Choose a template for its structure and tone, then replace the sample content. If none fits, start
  with `blank` and let the agent build from the brief.
</Tip>
