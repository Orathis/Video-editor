## Variables

| Name | Type | Default | Description |
| --- | --- | --- | --- |
| `kicker` | `string` | `Q3 RESULTS` | Small line above the message. |
| `headline` | `string` | `Revenue doubled` | The message the focus resolves onto. |
| `accent` | `enum` | `amber` | Foreground bokeh colour. |

## When to use it

Attention must transfer once from a near plane to a message on a far plane.

## When to avoid it

Avoid it when animated blur is unacceptable, because blur on the foreground and message planes is the stated focus mechanic.
