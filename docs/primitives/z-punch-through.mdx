## Variables

| Name | Type | Default | Description |
| --- | --- | --- | --- |
| `front` | `string` | `BEFORE` | Text on the wall the camera punches through. |
| `back` | `string` | `AFTER` | Text on the plane behind the wall. |
| `accent` | `enum` | `blue` | Light behind the aperture. |

## When to use it

A scene change must feel like forward travel through an aperture rather than a flat scale zoom.

## When to avoid it

Avoid it when the clip needs a hold, because the documented 2.10-second envelope is filled by the move and has no hold.
