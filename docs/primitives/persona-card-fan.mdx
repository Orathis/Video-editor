## When to use it

Options must appear beside a presenter while the deepest card stays pinned and newer cards subdivide the same fan.

## When to avoid it

Avoid it when portrait or square framing must be as fully composed as landscape, because those aspects are only kept inside the frame and the move is composed for 16x9.
